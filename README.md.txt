# Personal Finance & Expense Analytics Dashboard

## Project Overview
This project analyzes personal income, expenses, monthly budgets, and savings using Excel, MySQL, and Power BI. It helps users understand their spending patterns and track their financial performance.

## Tools & Technologies
- **Microsoft Excel:** Dataset preparation and data cleaning
- **MySQL:** Data storage, SQL queries, and financial analysis
- **Microsoft Power BI:** Interactive dashboard and visualizations

## Dashboard Features
- Total income, total expenses, and net savings KPIs
- Monthly income vs. expenses comparison
- Expense breakdown by category
- Monthly net savings analysis
- Currency formatting in Indian Rupees (₹)

## Key Insights
- Total income: ₹60,000
- Total expenses: ₹33,400
- Net savings: ₹26,600
- January net savings: ₹14,100
- February net savings: ₹12,500

*These results are based on the sample dataset for January and February 2026.*

## Project Files
- `Personal_Finance_Analytics.xlsx` — Excel dataset
- `finance_analysis.sql` — SQL scripts and analysis queries
- `Personal Finance Analytics Dashboard.pbix` — Power BI report

## How to Use
1. Download the project files.
2. Run the SQL scripts in MySQL Workbench.
3. Open the `.pbix` file in Power BI Desktop.
4. Update the data source connection if required, then refresh the report.
